# 06 — UI

React + Vite. A pure client of Core over the HTTP/WebSocket API. No business
logic; it renders Core state and sends user actions (sign-offs, comments,
intent) back through Core operations. Served by `skipper up`.

## Views
- **Dashboard** — the project dissected into sprints. Shows each sprint, its
  goal, its link to a roadmap initiative, and overall progress. Drill into a
  sprint to reach its kanban.
- **Kanban** — per sprint. Columns are the stages (intake, adr, plan, build,
  check, ship, watch, retro). Each card is a task/stage showing who is working it
  (which persona), status, and the active artifact. Derived entirely from the
  sprint files' `stages[].status`.
- **Inbox** — the live message + audit stream, rendered from `log.jsonl`. Shows
  agent-to-agent handoffs, agent-to-human questions, and human replies, each with
  actor, timestamp, and sprint/stage reference. Pending sign-offs surface here
  with approve/reject controls. The inbox view and the audit trail are the same
  data.

## Behavior
- Live updates over the WebSocket; no polling.
- Sign-off controls call Core's sign-off operation; Core records the human
  principal. The UI cannot fabricate a sign-off any more than an agent can.
- Everything visible here has a CLI equivalent (see `05-cli.md`); the UI adds
  visualization, not capability.

## Non-goals
No multi-tenant admin, no billing, no org-management sprawl. One project view per
attached repo (multiple repos = switch projects).
